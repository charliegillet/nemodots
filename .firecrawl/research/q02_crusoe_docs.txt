Getting Started with Serverless Inference - Crusoe Cloud
  URL: https://docs.crusoecloud.com/quickstart/getting-started-with-serverless-inference/

The models are hosted on Crusoe's inference engine with MemoryAlloy, a proprietary cluster-wide memory fabric with cache-aware routing that improves TTFT and throughput.

All models are accessible via the `api.inference.crusoecloud.com` path.

## Querying Text models [​](https://docs.crusoecloud.com/quickstart/getting-started-with-serverless-inference/#querying-text-models)
```python
import os

from openai import OpenAI

CRUSOE_API_KEY = os.getenv("CRUSOE_API_KEY")

client = OpenAI(

    api_key=CRUSOE_API_KEY,

    base_url="https://api.inference.crusoecloud.com/v1",

)

completion = client.chat.completions.create(

    model="meta-llama/Llama-3.3-70B-Instruct",

    messages=[\
\
        {"role": "system", "content": "You are a helpful, concise assistant."},\
\
        {"role": "user", "content": "Who is Robinson Crusoe?"},\
\
    ],

)

print(completion.choices[0].message.content)
```
