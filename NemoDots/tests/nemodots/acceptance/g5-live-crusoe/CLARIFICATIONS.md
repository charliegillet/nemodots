## New dependencies recorded by this revision

- ModelCallRecord and ContextSnapshot are not on the `model_call.recorded` event variant. The suite reads them from `GET /missions/:id/evidence` or the mission snapshot as `modelCalls` / `contextSnapshots`; a route must expose them (G5.3b, G5.3c, G5.3e).
- A second app instance on `NEMODOTS_ACC5_PROXIED_APP_URL` (default http://127.0.0.1:4702) whose `OPENAI_BASE_URL` is `http://127.0.0.1:${NEMODOTS_ACC5_PROXY_PORT:-4710}/v1`, the verifier proxy the suite binds (G5.4l).
- A configurable inference timeout (e.g. `NEMODOTS_INFERENCE_TIMEOUT_MS`) would shorten G5.4k, which now waits out the real 60 s.
- A fault-driven "mutating tool never auto-retried" case needs the `NEMODOTS_TEST_HOOKS` barrier `after_effect_before_record`; G5.4m checks the invariant on live mission data only.
- G5.8d drives an OpenDots chat turn with `src/server/headless.ts#runThreadTurn` against `/api/copilotkit`; the summary must exclude it or label it in a separate bucket.
