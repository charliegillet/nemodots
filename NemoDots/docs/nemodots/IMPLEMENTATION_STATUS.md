# NemoDots implementation status and reviewed task contracts (revision 2)

Maintained by the lead/integrator only. Contract version for every package: **v1** (`src/server/nemodots/contracts`, revision 2 of `CONTRACTS.md`). Status values: PLANNED, IN_PROGRESS, PASS, FAIL, BLOCKED, NOT_RUN. Builders report with the handoff JSON from `BUILD_PROMPT.md`; the lead copies the status here. Owner strings are role names; packages in one wave that share a role label are built by separate agents.

Global rules for every package: stay inside `allowedFiles`; report other needed edits as dependencies; no git except the integrator; never print or commit secrets; never touch Postgres 5432 / Redis 6379; stop every process you start; no silent fallback provider (and no default `OPENAI_BASE_URL` anywhere); PASS/FAIL/BLOCKED/NOT_RUN only; never weaken a test; never present fixtures as live; all `docs/nemodots/*.md` Prettier-clean; the five upstream gates (`check-format`, `lint`, `typecheck`, `test`, `build`) must stay green after your change (run them, record exit codes). Server imports use `.js` suffixes (NodeNext). Unit tests under `tests/nemodots/<area>/` need no network and no running stack; DB-backed tests go under `tests/nemodots/integration/<area>/` and use `tests/nemodots/helpers/test-db.ts`, which returns **per-role URLs** (`admin`, `app`, `checkout`, `injector`, `verifier`) for a fresh `nemodots_test_<rand>` database on 55432. Self-write and action tests use the `app` URL (the `config_entries` trigger nulls `caused_by_action_id` for every other role, admin included).

Reserved for the independent verifier, never in any `allowedFiles`: `tests/nemodots/acceptance/**`, `evals/nemodots/frozen/**`, `docs/nemodots/VERIFICATION_REPORT.md`.

Wave gate: the integrator runs the five upstream gates plus `npm run test:nemodots:db` (from W2 on) after each wave, records results in section 8, and commits with explicit paths.

Review findings C1-C16, I1-I14, D1-D10 (ARCHITECTURE.md section 14) are folded into the contracts below; each package's acceptance list names the finding ids its tests close.
