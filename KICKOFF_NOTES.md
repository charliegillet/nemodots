# Kickoff Notes

Notes from the opening session of the Recursive Agents Hackathon: partner talks, schedule, rules, themes and prizes.

   * NeMo family covers intelligence, efficiency, and openness across model sizes
   * NeMoPro 3.5 released yesterday; post-training recipes open-sourced

   * NeMoSwitch: routes queries to right model size based on complexity
   * Blueprints at docs.nvidia.com / GitHub: production-ready, swappable for hackathon use
   * Special prize: one GPU awarded for best use of NeMo
* Crusoe (Connor): managed AI inference cloud
   * Intelligence Foundry hosts leading open-source models (DeepSeek, GLM, KimiK, etc.) behind a single API key
   * OpenAI-compatible API endpoint; works with LangChain, Pydantic, and similar tools
   * Free credits: $50 per person, claimed via form (org ID + email); credits reflect at month-end
   * Set API key expiry to tomorrow to avoid unexpected charges
   * Crusoe skill file in GitHub repo: drop into any coding assistant as a built-in support engineer
   * Raffle at Crusoe table; swag and hoodies available

## Schedule and Rules

* Hacking starts now
* Lunch at 1 PM; submissions due at 5 PM on the Cerebral Valley platform
* First-round judging: 5:00 to 6:45 PM (teams called to back rooms, 3-min pitch + 2-min Q&A)
* Final judging: 7:00 to 8:00 PM (top 6 projects on stage, same format)
* Winners announced at 8 PM; venue open until 10 PM
* Team size: 1 to 4 members, no more than 4
* All projects must be open-source with a public GitHub repo
* All work must be built from scratch at this hackathon; no Figma, no pre-existing private repos
* Submission requires: 1-minute demo video (public: YouTube, Loom, etc.), GitHub link, project description, and partner feedback

## Themes and Prizes

* Three required themes (pick one for submission):
   1. Done Means Done: agent defines and verifies its own success
   2. Shared Brain: shared context layer across multiple agents
   3. Version n+1: agent improves itself over time on its task

   * 2nd: $8,000 cash + $500 [You.com](https://you.com) credits
   * 3rd: $3,000 cash + $250 [You.com](https://you.com) credits
